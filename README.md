## LXC vs KVM：为什么 ByteVirt 的 LXC 套餐更便宜？

很多人搜"ByteVirt LXC VPS"的时候，其实心里有个疑问：同样的配置，为什么 LXC 比 KVM 便宜这么多？这里简单说一下原理，方便你判断自己适不适合上 LXC。

LXC 是操作系统级虚拟化，所有容器共享宿主机的 Linux 内核，不需要像 KVM 那样为每个虚拟机模拟一整套硬件。好处是开销小、启动快、相同价钱能拿到更多内存和流量；代价是隔离性弱，理论上一个容器里的 root 用户如果利用内核漏洞，可能影响同宿主的其他容器。对于个人学习、跑可信程序、做代理中转这类场景，LXC 的隔离性完全够用；但如果你要跑多租户业务、对外提供公共服务、对安全隔离有强要求，那还是 KVM 更稳妥。

ByteVirt 同时提供 LXC 和 KVM 两种虚拟化，LXC 系列主打低价 NAT，KVM 系列主打独立 IP 和 CN2 GIA 优化线路。如果你只是想花最少的钱多开几台小鸡，LXC NAT 是更经济的选择；如果你需要稳定独立 IP、跑生产业务、对线路质量有要求，那建议看 KVM 系列。
